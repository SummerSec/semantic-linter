# CLAUDE.md

This repository contains Semantic-Linter, a plugin and CLI for narrowing wide-boundary wording in instruction files.

## Core Commands

```bash
npm test
npm run scan -- <file>
npm run build-lexicon
npm run build-lexicon:check
npm run build-rules
npm run build-rules:check
```

## Current Runtime Design

Semantic-Linter uses a layered design:

- `SessionStart` injects a compact semantic rules pointer.
- `SubagentStart` mirrors that pointer into subagents.
- `UserPromptSubmit` can scan user prompts.
- `PreToolUse` warns before `Write` and `Edit` for instruction files.
- `PostToolUse` re-checks the resulting content and updates escalation state.
- `bin/scan.js` remains the explicit CLI scanner.

Default mode is `guarded`.

- `off`: disable Semantic-Linter behavior
- `pointer`: pointer only
- `guarded`: pointer plus write-time checks
- `strict`: pointer plus write-time checks plus prompt scanning

Project rules are resolved with `project-first` behavior by default. The nearest `semantic-rules.md` wins; the plugin-bundled rules file is the fallback.
